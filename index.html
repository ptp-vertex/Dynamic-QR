API & Webhooks

ห้ามเปิดเผย API Key ให้บุคคลอื่นทราบเด็ดขาด — ถ้ากด "สร้างใหม่" คีย์เก่าจะใช้งานไม่ได้ทันที

API Base URL

https://asia-southeast1-dynamic-qr-42c99.cloudfunctions.net/api

POST /v1/qr — สร้าง Dynamic QR ใหม่

curl -X POST "https://asia-southeast1-dynamic-qr-42c99.cloudfunctions.net/api/v1/qr" \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"destination":"https://example.com","name":"โปรโมชั่นหน้าร้าน"}'

GET /v1/qr — รายการ QR ทั้งหมด

curl "https://asia-southeast1-dynamic-qr-42c99.cloudfunctions.net/api/v1/qr" \
  -H "X-API-Key: YOUR_API_KEY"

GET /v1/qr/:id/stats — ดึงสถิติการสแกน

curl "https://asia-southeast1-dynamic-qr-42c99.cloudfunctions.net/api/v1/qr/QR_ID/stats" \
  -H "X-API-Key: YOUR_API_KEY"
